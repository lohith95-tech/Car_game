# 🚗 Neon Drive — Retro Car Game

A fast-paced, top-down arcade car driving game inspired by Dr. Driving.
Built with pure HTML5 Canvas and Vanilla JavaScript — no frameworks, no dependencies.

## 🎮 How to Play

- **Arrow Keys / WASD** — Steer, Accelerate & Brake
- **Mobile** — Use on-screen touch buttons
- Dodge traffic cars and collect ⭐ coins to increase your score
- Speed increases over time — how long can you survive?

## ✨ Features

- Infinite scrolling road with neon lane markers
- 3–5 types of traffic cars with random spawning
- Coin collection system (+10 pts per coin)
- Particle explosion effect on collision
- Best score saved automatically (localStorage)
- Fully responsive — works on mobile & desktop
- Smooth 60fps gameplay

## 🛠️ Built With

- HTML5 Canvas API
- Vanilla JavaScript
- CSS3
- Google Fonts (Orbitron)
